01

Vue Setup

Bootstrapping apps via CDN or build tooling.

CDN quick start

<div id="app">{{ message }}</div>
<script src="https://unpkg.com/vue@3/dist/vue.global.prod.js"></script>
<script>
const { createApp } = Vue;
createApp({
  data: () => ({ message: 'Hello Vue' })
}).mount('#app');
</script>

Use for prototypes or embeds; no bundling.

Vite + Vue

npm create vite@latest my-app -- --template vue
cd my-app && npm install && npm run dev

Modern tooling with HMR, TypeScript, tests. Keep app structure: App.vue + /components.

Single File Component anatomy

<template>
  <Button :label="count" @click="increment" />
</template>

<script setup>
import Button from './Button.vue';
const count = ref(0);
const increment = () => count.value++;
</script>

<style scoped>
button { font-weight: 600; }
</style>

Use <script setup> for concise components.

Mounting

import { createApp } from 'vue';
import App from './App.vue';

createApp(App)
  .provide('apiBase', 'https://api.example.com')
  .mount('#app');

Chain plugins (.use), directives (.directive), or mixins before mount().

02

Template Syntax & Directives

Interpolation, bindings, and logic with full modifier coverage.

Interpolation

<h1>Hello {{ user.name.toUpperCase() }}!</h1>

Only expressions allowed (no statements). Auto-escapes HTML.

v-bind / :

<img :src="avatarUrl" :alt="`Avatar of ${user.name}`" />
<component :is="dynamicComponent" />
<MyButton v-bind="buttonProps" />
  • Arguments: v-bind:class, :[dynamicAttr].
  • Modifiers: .prop force DOM property, .camel convert to camelCase, .attr explicit attribute (default).
  • When to use: reactive attribute/prop binding, dynamic component selection.

v-on / @

<button @click.stop="save" @mouseenter="hover = true" />
<input @keyup.enter="submit" />
<form @submit.prevent="submit" />

Native events

click, dblclick, contextmenu, input, change, focus, blur, submit, keydown, keyup, keypress, mouseenter, mouseleave, mousemove, wheel, touchstart, touchend, drag, drop, scroll.

Modifiers

.stop stopPropagation · .prevent preventDefault · .capture add capture listener · .once auto-remove · .passive passive mode (no preventDefault) · .self only when target is element itself · .exact exact modifier key match · key modifiers (.enter, .esc, .ctrl, .shift, .alt, .meta) · .left/.right/.middle mouse buttons · .native legacy when listening on child component root.

Conditional rendering

<p v-if="status === 'success'">Done</p>
<p v-else-if="status === 'loading'">Loading...</p>
<p v-else>Failed</p>
<p v-show="isVisible">Display toggled via CSS (no destroy).</p>

Use v-if for expensive DOM, v-show for frequent toggles.

v-for

<li v-for="(todo, index) in todos" :key="todo.id">
  {{ index + 1 }}. {{ todo.title }}
</li>
<template v-for="(value, key) in stats" :key="key">...</template>

Provide unique :key; avoid using index unless data is static.

v-model

<input v-model.trim="form.email" />
<input type="number" v-model.number="form.age" />
<textarea v-model.lazy="bio" />
<MyInput v-model="search" />
<MySlider v-model:value="range" />
<MyToggle v-model:checked="isOn" v-model:label="label" />

Modifiers: .lazy update on change, .trim auto-trim strings, .number cast to number. Arguments (v-model:prop) allow multiple two-way bindings. Components can define modelValue/update:modelValue or defineModel.

Directive summary

Directive Key options Use case
v-html Inject raw HTML (sanitize yourself). Use for trusted markdown output.
v-text Sets textContent. Shorthand for plain text injection.
v-memo Cache subtree until dependency array changes. Optimize expensive static blocks.

03

Components

Registration, props, emits, and slots.

Registration

// main.js global
createApp(App)
  .component('BaseButton', BaseButton)
  .mount('#app');

// Local
import BaseCard from './BaseCard.vue';
export default {
  components: { BaseCard }
};

Prefer auto-import or local registration to reduce bundle size.

Props

const props = defineProps({
  label: { type: String, required: true },
  count: { type: Number, default: 0 },
  config: { type: Object, default: () => ({}) }
});

Validate types, provide defaults via factory for objects/arrays. Use defineEmits for TypeScript inference.

Emits + .sync

const emit = defineEmits({
  submit: (payload) => payload !== null,
  'update:modelValue': (val) => typeof val === 'string'
});

emit('submit', formData);

<MyDialog v-model="isOpen" @submit="save" />
<MyDialog :visible="isOpen" @update:visible="isOpen = $event" />

.sync sugar became v-model:prop.

Slots

<Modal>
  <template #header>Title</template>
  Default content
  <template #footer>
    <button @click="close">Close</button>
  </template>
</Modal>

Named slots via #name. Provide fallback using slot content inside component.

Scoped slot

<List :items="users">
  <template #default="{ item, index }">
    {{ index + 1 }} - {{ item.name }}
  </template>
</List>

Expose slot props from child via <slot :item="item" />.

04

Reactivity (Composition API)

State containers, derived values, and effects.

ref

const count = ref(0);
count.value++;

Holds primitive or complex value. Unwrapped in templates.

reactive

const state = reactive({ user: null, loading: false });
state.loading = true;

Proxy-based; mutate directly. Use toRefs() when spreading into components.

computed

const fullName = computed(() => `${user.value.first} ${user.value.last}`);

Cached until dependencies change. Can be writable via getter/setter.

watch

watch(() => route.params.id, (id, prev) => {
  fetchUser(id);
}, {
  immediate: true,
  deep: false,
  flush: 'pre'
});

Options: immediate, deep, flush ('pre' | 'post' | 'sync'), onTrack/onTrigger dev hooks.

watchEffect

watchEffect((onCleanup) => {
  const stop = subscribeToChannel(channelId.value);
  onCleanup(() => stop());
});

Auto tracks dependencies inside callback. Good for syncing imperative APIs.

05

Lifecycle Hooks

Composition helpers and Options API equivalents.

Hook Composition API Options API Usage
Before mount onBeforeMount() beforeMount Access props, avoid DOM.
Mounted onMounted() mounted DOM available, start subscriptions.
Before update onBeforeUpdate() beforeUpdate Read pre-patch DOM.
Updated onUpdated() updated Interact with post-patch DOM.
Before unmount onBeforeUnmount() beforeUnmount Cleanup timers, listeners.
Unmounted onUnmounted() unmounted Detach services, sockets.

Example

import { onMounted, onUnmounted } from 'vue';
const interval = ref();

onMounted(() => {
  interval.value = setInterval(fetchStats, 5000);
});

onUnmounted(() => clearInterval(interval.value));

06

Methods & Computed

Encapsulate business logic and derived state.

Methods

const increment = () => count.value++;

export default {
  methods: {
    increment() {
      this.count++;
    }
  }
};

Use for actions that may receive arguments or have side effects.

Computed vs method

const filtered = computed(() => items.value.filter(matches));

<div v-for="item in filtered" :key="item.id" />

Computed caches until dependencies change; methods re-run on each render. Use computed for derived data without side effects.

07

Event Handling

Native events, modifiers, and component communication.

Native events

  • Keyboard: @keyup.enter, @keydown.ctrl.s.
  • Form: @submit.prevent, @change, @input.
  • Mouse: @click.stop, @dblclick, @contextmenu.prevent.
  • Focus: @focus, @blur.

Modifiers quick lookup

.stop stopPropagation()
.prevent preventDefault()
.once Listener runs once
.self Only if event.target === currentTarget
.passive Hint for scroll performance
.capture Use capture phase
.exact Exact modifier combination
.native Listen on child root (compat)

Custom events

// Child
const emit = defineEmits(['submit']);
const handleClick = () => emit('submit', form.value);

// Parent
<FormCard @submit="save" />

Document events for consumers. Use defineEmits for TS types.

08

Conditional Rendering & Lists

Control DOM output and iterate data safely.

v-if vs v-show

<Alert v-if="error" :message="error" />
<Tooltip v-show="hover" />

v-if removes DOM entirely (costly but ensures teardown). v-show toggles CSS display; perfect for frequent toggles.

Loop best practices

  • Always supply stable :key (primary key, slug).
  • Use v-for="(value, key, index) in object" for objects.
  • Avoid nested v-for with same key to prevent patch conflicts.

09

Forms & v-model

Two-way binding patterns for every input type.

Text inputs

<input v-model.trim="form.email" type="email" />
<textarea v-model.lazy="form.notes" />

Use .trim to strip whitespace; .lazy to update on blur/change.

Checkbox & radio

<input type="checkbox" v-model="form.agree" />
<input type="checkbox" value="dark" v-model="form.themes" />
<input type="radio" value="monthly" v-model="plan" />

Checkbox supports boolean or array. For radios, ensure same name.

Select

<select v-model.number="form.countryId">
  <option :value="null" disabled>Select...</option>
  <option v-for="c in countries" :value="c.id" :key="c.id">
    {{ c.name }}
  </option>
</select>

Use multiple with array binding for multi-select.

10

Computed & Watch

Pick the right tool for derived state or side effects.

Computed cheat

  • Use when output is deterministic & derived from reactive sources.
  • Writable variant: computed({ get, set }) for two-way formatting.

watch options

  • Sources: single ref, getter fn, array of sources.
  • deep: true for nested objects (expensive, prefer specific watchers).
  • flush: 'post' to run after DOM update for animation hooks.
  • immediate: true run once instantly.

Vue Router Basics

Navigation, dynamic routes, and views.

Setup

import { createRouter, createWebHistory } from 'vue-router';
import Home from './pages/Home.vue';
import User from './pages/User.vue';

const routes = [
  { path: '/', component: Home },
  { path: '/users/:id', name: 'user', component: User, props: true }
];

export const router = createRouter({
  history: createWebHistory(),
  routes,
  scrollBehavior: () => ({ top: 0 })
});

createApp(App).use(router).mount('#app');

Usage

<router-link :to="{ name: 'user', params: { id: 42 } }">
  Profile
</router-link>
<router-view v-slot="{ Component }">
  <transition name="fade">
    <component :is="Component" />
  </transition>
</router-view>

Grab current route via const route = useRoute(); push via const router = useRouter().

State Management (Vuex / Pinia)

Centralized stores for complex apps.

Pinia store

import { defineStore } from 'pinia';
export const useUserStore = defineStore('user', {
  state: () => ({ user: null }),
  getters: {
    isAdmin: (state) => state.user?.role === 'admin'
  },
  actions: {
    async fetchUser() {
      this.user = await api.me();
    }
  }
});

const store = useUserStore();
store.fetchUser();

Vuex (legacy)

const store = createStore({
  state: () => ({ count: 0 }),
  mutations: {
    increment(state) { state.count++; }
  },
  actions: {
    incrementAsync({ commit }) {
      setTimeout(() => commit('increment'), 250);
    }
  },
  getters: {
    double: (state) => state.count * 2
  }
});

Pinia is the recommended store for Vue 3 (lighter API, TS friendly).

14

Composition API Utilities

Patterns for dependency injection and script setup ergonomics.

provide / inject

// parent
provide('theme', ref('dark'));

// child
const theme = inject('theme', ref('light'));

Use symbols for type safety; default value used if provider missing.

defineProps / defineEmits / defineExpose

const props = defineProps<{ label: string }>();
const emit = defineEmits<{ (e: 'select', value: string): void }>();

const focus = () => input.value?.focus();
defineExpose({ focus });

Works only inside <script setup>. Expose methods for parent refs.

Common Directives / Helpers

Less-used utilities worth remembering.

v-pre

Skips compilation for block. Use to show literal mustache syntax.

<code v-pre>{{ raw }}</code>

v-cloak

Hide until app hydrated. Pair with CSS.

[v-cloak] { display: none; }

v-once

Render element/component only once; skips future updates.

<HeroBanner v-once :config="config" />

Filters?

Filters were removed in Vue 3. Replace with computed properties or methods.

16

Tips & Gotchas

Battle-tested notes for production Vue apps.

Reactive caveats

  • Directly reassigning reactive objects (state = {}) loses reactivity; use Object.assign(state, newState).
  • Mutating arrays via index works, but use splice when removing to keep watchers aware.
  • When using reactive, destructuring breaks reactivity. Convert with toRefs.

Performance & UX

  • Key list items deterministically to avoid DOM reuse bugs.
  • Wrap expensive components with defineAsyncComponent + suspense.
  • Use v-memo and shallowRef for static heavy blocks.
  • Prefer script setup + defineModel for single-source-of-truth two-way binding.
Keep this Vue.js cheatsheet handy for daily development. Validate directives, prefer composition utilities, and profile before optimizing.
