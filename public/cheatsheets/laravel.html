01

Project Setup & Environment

Bootstrap new apps fast and lock configuration.

Core basics

Create project

Installs latest Laravel skeleton.

composer create-project laravel/laravel blog

Serve locally

Starts PHP dev server.

php artisan serve --host=0.0.0.0 --port=8080

.env basics

Config lives in env vars.

cp .env.example .env && php artisan key:generate

Key generation

Sets APP_KEY for encryption.

php artisan key:generate --show

env() vs config()

Use env only in config files.

// config/services.php
'stripe' => [
  'key' => env('STRIPE_KEY'),
]
// elsewhere: config('services.stripe.key')

02

Directory Structure Overview

Know where everything lives.

app/

Core code (models, services, jobs, policies).

routes/

web.php, api.php, console.php, channels.php.

database/

Migrations, factories, seeders.

resources/

Blade views, assets, lang files.

public/

Web root, compiled assets, index.php.

storage/

Logs, cache, framework, user uploads.

config/

App configuration files loaded at boot.

04

Routing

Map HTTP verbs to controllers gracefully.

Basics & params

Route::get('/', fn () => view('welcome'));
Route::get('/posts/{post}', [PostController::class, 'show']);
Route::get('/users/{user?}', fn ($user = null) => $user);

Named routes

Route::post('/login', AuthController::class)->name('login');
return redirect()->route('login');

Groups & middleware

Route::middleware(['auth', 'verified'])
    ->prefix('dashboard')
    ->name('dashboard.')
    ->group(function () {
        Route::get('/', [DashboardController::class, 'index'])
            ->name('home');
    });

Resource & binding

Route::resource('posts', PostController::class);
Route::model('post', Post::class);
Route::bind('slug', fn ($value) => Post::whereSlug($value)->firstOrFail());

05

Controllers

Keep logic tidy.

Resource controllers

class PostController extends Controller
{
    public function store(StorePostRequest $request)
    {
        Post::create($request->validated());
        return redirect()->route('posts.index');
    }
}

Single-action

class PublishPost extends Controller
{
    public function __invoke(Post $post)
    {
        $post->publish();
        return back();
    }
}
Route::post('/posts/{post}/publish', PublishPost::class);

Dependency injection

public function index(Request $request, ReportService $service)
{
    return $service->forUser($request->user());
}

06

Requests & Validation

Keep data clean at the boundary.

Request helpers

$request->input('email');
$request->only(['name','email']);
$request->boolean('active');

Form request

class StorePostRequest extends FormRequest
{
    public function rules()
    {
        return [
            'title' => 'required|string|max:255',
            'body' => 'required',
        ];
    }
}

Common rules

'email' => 'required|email:rfc,dns'
'password' => 'required|min:12|confirmed'
'photo' => 'nullable|image|max:2048'

Custom messages

public function messages()
{
    return ['title.required' => 'Add a title before publishing.'];
}

07

Blade Templating

Render HTML with clean syntax.

Layouts & sections

// resources/views/layouts/app.blade.php
<html>
  <body>
    @yield('content')
  </body>
</html>
// page
@extends('layouts.app')
@section('content')
  <h1>Dashboard</h1>
@endsection

Conditionals & loops

@if($posts->isEmpty())
  <p>Nothing yet.</p>
@endif
@foreach($posts as $post)
  <li>{{ $post->title }}</li>
@endforeach

CSRF & methods

<form method="POST" action="/posts">
  @csrf
  @method('PATCH')
</form>

Output

Escaped: {{ $post->title }}
Raw (trusted only): {!! $post->body !!}

08

Database & Migrations

Version your schema.

Migration structure

Schema::create('posts', function (Blueprint $table) {
    $table->id();
    $table->string('title');
    $table->text('body');
    $table->timestamps();
});

Column types

$table->string('slug')->unique();
$table->boolean('published')->default(false);
$table->foreignId('user_id')->constrained();

Indexes & FK

$table->index('status');
$table->foreign('team_id')
      ->references('id')->on('teams')
      ->onDelete('cascade');

Rollbacks

php artisan migrate
php artisan migrate:rollback --step=1
php artisan migrate:fresh --seed

09

Eloquent ORM

Expressive database layer.

CRUD & mass assignment

Post::create($request->validated());
$post = Post::findOrFail($id);
$post->update(['title' => 'New']);
$post->delete();
protected $fillable = ['title','body'];

Helpers

Post::firstOrFail();
Post::updateOrCreate(['slug' => $slug], [...]);
Post::pluck('title','id');

Relationships & eager loading

class Post extends Model
{
    public function author()
    {
        return $this->belongsTo(User::class, 'user_id');
    }
    public function tags()
    {
        return $this->belongsToMany(Tag::class);
    }
}
$posts = Post::with(['author', 'tags'])->latest()->get();

13

Middleware

Intervene during the request lifecycle.

Create middleware

php artisan make:middleware EnsureTeamMember
public function handle($request, Closure $next)
{
    abort_unless($request->user()->onTeam(), 403);
    return $next($request);
}

Global vs route

// app/Http/Kernel.php
protected $middleware = [...]; // global
protected $routeMiddleware = [
  'team' => EnsureTeamMember::class,
];
Route::middleware('team')->group(...);

14

Error Handling & Logging

Fail loudly, log meaningfully.

abort()

abort_if(! $user->isAdmin(), 403);

try/catch

try {
    $service->sync();
} catch (Throwable $e) {
    report($e);
    return back()->withErrors('Sync failed');
}

Log levels

Log::debug('Payload', $data);
Log::info('User login', ['id' => $user->id]);
Log::warning('High latency');
Log::error('Unhandled exception', ['error' => $e->getMessage()]);

15

Queues, Jobs & Events

Offload heavy work and decouple.

When to use

Emails, reports, webhooks, long API calls.

Job skeleton

class SendReport implements ShouldQueue
{
    public function handle(ReportService $service)
    {
        $service->deliver();
    }
}
dispatch(new SendReport($report));

Events & listeners

event(new InvoicePaid($invoice));
class SendReceipt
{
    public function handle(InvoicePaid $event)
    {
        Mail::to($event->invoice->user)->send(...);
    }
}

Workers

php artisan queue:work --tries=3 --max-time=3600

20

Common Gotchas & Tips

Quick fixes when things feel cursed.

  • Cache issues: run php artisan config:clear then cache:clear.
  • Route not updating: php artisan route:clear.
  • Permission errors: ensure web user can write storage & bootstrap/cache.
  • 419 errors: session expired or missing CSRF token; check domain & session driver.

Debug quickies

dump($variable);
dd($payload);
logger()->info('Checkpoint');
php artisan tinker
